# Man-in-the-Middle Attack Simulation – ARP Spoofing (Educational Lab)

## Objective
This project aims to understand Man-in-the-Middle (MITM) attacks based on ARP
spoofing techniques and to analyze their impact on network communications
in a controlled laboratory environment.

## Lab Environment
- Operating Systems: Kali Linux, Windows
- Network: Isolated virtual network
- Attack Technique: ARP spoofing
- Analysis Tools: Wireshark, Ettercap

## Scope
The project focuses on:
- ARP protocol behavior
- Network traffic interception risks
- Detection of abnormal ARP activity
- Mitigation strategies against MITM attacks

## Methodology (High-Level)
- Design of a virtual network with attacker and victim machines
- Simulation of ARP spoofing to redirect traffic
- Capture and analysis of network packets
- Identification of unencrypted communications

## Detection & Mitigation
- Detection of ARP poisoning through abnormal ARP replies
- Traffic inspection using Wireshark
- Discussion of HTTPS, ARP inspection, and secure network segmentation

## Disclaimer
This project was conducted strictly in a controlled lab environment
for educational purposes only.
